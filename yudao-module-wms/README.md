# MzMedia - 智能仓储与备品备件中心 (`yudao-module-wms`)

## 📌 模块定位与职责

`yudao-module-wms` 是 MzMedia 的仓储中枢，覆盖从**企业物资供应链管理**到**物联网工程备品备件管控**的全套仓储业务。

在工业物联网与工程实施项目中，传感器探头、工控网关、电源适配器等核心硬件与备件的流动频繁。`yudao-module-wms` 提供了从**多级仓库库位建模、物料批次与序列号 (SN) 追踪、动态入库出库流转、到工程项目物料预占与先进先出（FIFO）**的严密仓储闭环。

```text
                             │
                             ▼
 ┌────────────────────────────────────────────────────────┐
 │ 2. 库内精细化作业                                      │

 └────────────────────────────────────────────────────────┘
```

## 💾 核心业务功能

### 1. 仓库主数据与空间建模 (`md`)
- **三级空间拓扑**：支持维护物理仓库（Warehouse） -> 功能库区（Zone，如立库区、备品备件区、不良品隔离区） -> 货架库位（Location）。
- **货主与多租户隔离**：支持多货主模式与多租户数据物理隔离，支撑多企业或跨厂区仓储代管。
- **物料规则定义**：支持针对传感器、PLC 等高价值精密硬件开启强制 SN 序列号管理与防重码校验。

### 2. 出入库全单据流转 (`order`)
- **入库作业**：采购到货入库单、生产完工报产入库单、现场退料入库单。
- **出库作业**：项目工程领料出库单、生产车间发料单、销售发货出库单。
- **库内管理**：移库调拨单（支持按单移库与库位整理）、盘点单（支持盲盘/实盘、盘盈盘亏自动生成损益单）。

### 3. 库存精准控制与协同 (`inventory`)
- **库存多状态划分**：严密管控“实时在库”、“单据预占冻结”与“采购在途”库存，杜绝工程项目超发漏发。
- **先进先出 (FIFO)**：根据入库批次号与保质期自动推荐先入库硬件优先出库。
- **低水位智能预警**：关键网关或易耗传感器低于安全库存水位时，自动向工程主管发送补货告警。
