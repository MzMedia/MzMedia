# MzMedia - 数字化制造执行与设备运维中枢 (`yudao-module-mes`)

## 📌 模块定位与职责

`yudao-module-mes` 是 MzMedia 针对中小制造企业打造的**数字化车间制造执行与设备运维系统**。

传统工厂中，设备告警与生产排程往往各自为政：机床故障停机了，车间调度不知情；传感器异常了，只能等工件批量报废才发现。`yudao-module-mes` 依托与 `yudao-module-iot` 及 `yudao-module-media` 的深度联动，实现了**设备状态实时感知、工单排产与进度追踪、生产异常安灯（Andon）预警、设备故障联动报修工单**的工业闭环。

## 📂 核心包目录结构

```text
cn.iocoder.yudao.module.mes
├── controller         # 控制器层 (主数据, 计划, 维保, 生产, 质检, 线边仓)
├── dal                # 数据访问层 (实体 DO 与 MyBatis-Plus Mapper)
├── enums              # MES 领域枚举 (OrderStatus, TaskStatus, AndonLevel 等)
├── framework          # 框架扩展 (条码生成器, 工序上下文)
├── job                # 生产排班与设备维保计划定时触发器
└── service            # 业务服务层
    ├── cal            # ★ 生产日历、法定节假日、班组班次与轮班排程
    ├── dv             # ★ 设备资产台账、点检保养计划、故障报修工单
    ├── md             # ★ 主数据 (物料BOM、SOP作业指导书、工位工作站、编码规则)
    ├── pro            # ★ 生产流转 (工艺路线、生产工单、派工流转卡、报工、Andon安灯)
    ├── qc             # ★ 质量检验 (进料IQC、过程IPQC、出货OQC、缺陷代码库)
    └── wm             # ★ 车间线边仓 (生产领料/退料、批次管理、物料SN追踪)
```

## 💾 六大核心业务子系统

| 子系统模块 | 英文标识 | 核心业务职责与关键赋能 |
| :--- | :--- | :--- |
| **主数据管理** | `md` | 统一物料编码规则、产品物料清单 (BOM)、标准作业指导书 (SOP)、车间工位与工作站定义。 |
| **计划与排班** | `cal` | 工厂生产日历定制、早中夜三班轮转计划、法定节假日规则、班组人员出勤分配。 |
| **设备资产与维保**| `dv` | 设备台账全生命周期档案、定期点检计划、保养记录闭环；**与 IoT 告警自动联动派发维修工单**。 |
| **生产制造流转** | `pro` | 工艺路线设计、生产工单排产、工序派工流转卡（Card）、生产报工、异常安灯（Andon）一键呼叫。 |
| **全流程质量检验**| `qc` | 来料质检 (IQC)、过程巡检与工序质检 (IPQC)、出货质检 (OQC)、质检方案与不良缺陷原因沉淀。 |
| **车间物料与条码**| `wm` | 生产领退料管理、批次追踪、工件单品序列号 (SN) 条码绑定、工序间流转防差错。 |
