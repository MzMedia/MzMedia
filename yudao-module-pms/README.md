# MzMedia - 物联网工程项目交付与协同中心 (`yudao-module-pms`)

## 📌 模块定位与职责

`yudao-module-pms` 是 MzMedia 面向中小企业工程实施场景打造的**物联网项目交付全生命周期管理中枢**。

中小企业在承接智能化改造、智慧园区、智慧水务、消防监控等物联网工程时，普遍面临“工程现场散、人员流动大、设备安装混乱、交付资料缺失”的痛点。`yudao-module-pms` 提供了从**项目立项、现场勘测、设备调拨绑定、现场安装调试、敏捷工作项追踪、到竣工验收归档**的一站式管理体系，并内置企业级协同知识库（KB）。

## 💾 核心功能体系

### 1. 项目与敏捷交付中心 (`pm`)
- **项目全景看板**：直观展示项目健康度、里程碑进度、工时消耗率与人员负荷。
- **工作项追踪 (WorkItem)**：
  - **需求 (Requirement)**：客户业务需求与现场技术规范拆解；
  - **任务 (Task)**：现场布线、网络打通、摄像头点位固定等具体执行工单；
  - **缺陷 (Bug)**：现场联调发现的通信掉线、传感器数据漂移等问题追踪。
- **自定义工作流状态**：支持按项目类型自定义工作项流转状态（新建 -> 处理中 -> 现场复核 -> 已结项）。

### 2. 企业项目知识库 (`kb`)
- **多层级工程目录树**：支持按项目归档现场勘测图纸、CAD 接线拓扑、PLC 点位配置表、竣工验收报告。
- **多格式沉淀**：原生支持 Markdown 与富文本编辑器，支持图片拖拽上传与在线全屏预览。
- **文档权限与分享**：支持按部门、项目成员或外部交付人员授予查看、编辑权限，支持防篡改分享链接。
